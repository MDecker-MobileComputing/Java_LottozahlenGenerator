# Java-Kommandozeilenprogramm: Lottozahlengenerator #

<br>

Kommandozeilenprogramm mit Java zur Erzeugung von Lottozahlen-Tipps für Lottovarianten verschiedener Länder. 
Es wird dabei demonstriert, wie eine statistisch korrekte Zufallsstichprobe aus einer Grundgesamtheit bestimmt wird.

<br>

Beispielausgabe für deutsches Zahlenlotto:

```
Tipp 1: 9	11	13	25	41	46	

Tipp 2: 4	12	21	31	47	49	

Tipp 3: 1	9	16	27	35	36	

Tipp 4: 2	10	23	29	36	42	

Tipp 5: 9	28	32	42	47	49	
```
